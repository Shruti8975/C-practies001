1. Data Type -
1.char - 1 byte  means 8 bits
Range - signed and unsigned
-128 to 127 | 0 to 255

2.int - 4 byte means 32 bits
Range - signed and unsigned
-2.14 to 2.14 | 0 to 4.14

3.float - 4 byte means 32 bits
Range of signed only because unsigned compiler Error      +-1.2 \* 10^-38 to +-3.4\*10^38

4.double - 8 byte means 64 bits
+-2.3 \* 10^-308 to +-1.7\*10^308
